# Mockup kit

A vanilla CSS + JS kit (no build step) for drawing faithful mockups of the
iPhone app and the TUI. Design: `docs/feat/mobile-mockup-kit.md`. How an agent
uses it: `docs/MOCKUP-BRIEF.md`.

| File | What |
|---|---|
| `generated/tokens.css`, `generated/tui-tokens.css`, `generated/kit-data.json` | GENERATED by `bun run mockup-kit` from the source (palettes, type, radii, sizes, spacing, component style metrics, timings, glyphs, view-model tables). Never edit; the drift test fails until regenerated. |
| `kit.css`, `tui.css` | The look; every value a `var()` (a literal hex/px/ms — or a chosen number dressed as one, `calc(12 * 1px)` — fails the test, unless it is a named entry in `APPROXIMATIONS`, `scripts/mockup-kit/kit-rules.ts`). |
| `frame.css` | The device frame (iPhone 17 Pro, 402 × 874 pt) and the terminal ground: the only literals, because they are the device's. |
| `kit.js` (+ `kit.d.ts`) | Pure builders `K.<component>(props) → {html, a11y}`, `K.tui.*`, `K.extend` («nuovo»), `K.screen` (mount). |
| `index.html` | The catalogue. View it inlined: `bun scripts/mockup-kit.ts inline tools/mockup-kit/index.html`. |
| `calibration/cases.json` | Kit vs real screenshots: `bun scripts/mockup-kit.ts calibrate` (informational; needs Chrome and an e2e run). |

After changing a theme token, a timing in `apps/mobile/src/motion.ts`, a
manifest component's `StyleSheet.create` or a TUI token: `bun run mockup-kit`.
