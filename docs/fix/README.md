# `fix/` — bug-fix tasks

Defects in existing behaviour. One doc per task: `docs/fix/<slug>.md`, copied
from `docs/TASK-TEMPLATE.md`, on branch `fix/<slug>`. Reproduce before
diagnosing (AGENTS §1); ship the fix with a red-before-green regression test
(§9).

See **AGENTS.md §10** for the workflow (one task, one branch, one doc; four
signed sections: Context · Implementation · Execution · Review).
