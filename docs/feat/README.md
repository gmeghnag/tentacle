# `feat/` — feature tasks

New capabilities and improvements, including an **approved** refactor or perf
change. One doc per task: `docs/feat/<slug>.md`, copied from
`docs/TASK-TEMPLATE.md`, on branch `feat/<slug>`. A refactor/perf idea that is
still being decided lives in `docs/eval/` until approved.

See **AGENTS.md §10** for the workflow (one task, one branch, one doc; four
signed sections: Context · Implementation · Execution · Review).
