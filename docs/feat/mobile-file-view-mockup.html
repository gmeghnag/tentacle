File colorati nei tool (iPhone)

Quando un tool legge, modifica o scrive un file, il contenuto viene colorato secondo il tipo di file, come nella TUI. Il linguaggio si sceglie solo dall'estensione: un'estensione sconosciuta resta grigia. Il mockup include già le decisioni prese: Figtree medio per il testo in tema scuro, righe dei tool più piccole e grigie, nessuna ✓ sui passi riusciti, Read ed Edit senza durata, Edit con +N −M, anello grigio per «Thought», pallino ciano che lampeggia sul passo in corso.

Tema del telefono:

Oggi

Il contenuto è testo grigio senza colori; l'intestazione è la riga grezza del tool.

A · colori, senza numeri di riga consiglio

Più pulito sul telefono: lo spazio va al codice, e le righe lunghe vanno a capo di meno.

B · colori con i numeri di riga

Come la TUI: utile quando la lettura parte a metà file (qui dalla riga 1) o per citare una riga.

Il tuo esempio: MultiEdit lungo

Oggi il nome del file compare quattro volte (riga del passo, intestazione, «⎿ edited … with 2 edits», scheda) e il conteggio +78 −30 tre volte. Nel nuovo lo si dice una volta sola, nella riga del passo; il diff mostra le prime righe e «tocca per vedere tutto». Il codice è JavaScript dentro un file .html: va deciso se colorarlo (la TUI oggi non colora i file .html).

Oggi

Com'è nel tuo screenshot.

A · senza numeri di riga consiglio

Solo il segno + / − davanti, la zona («righe 87–135») al posto di «@@ -87,20 +87,48 @@».

B · con i numeri di riga

Un solo numero (quello nuovo; per le righe tolte quello vecchio), invece di due colonne.

Da decidere

  • A (senza numeri) o B (con i numeri)? Nel diff dell'Edit il segno + / − resta comunque, così una riga aggiunta o tolta si riconosce anche senza colore.
  • JavaScript e CSS dentro un file .html: li coloriamo (sul telefono si può, la TUI oggi lascia l'.html senza colori)?
  • Linguaggi: oggi l'app ne colora 14 (bash, css, diff, go, java, js, json, markdown, python, rust, sql, ts, html/xml, yaml). Ne aggiungiamo altri?
  • File molto grandi restano senza colori, come nella TUI (oltre 2000 righe o 200 KB), per non rallentare lo scorrimento.
