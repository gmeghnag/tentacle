- **A sentence of what a shell command does.** The model now describes each `shell` call in a few words, in your language; the TUI and the iPhone title the row with that sentence and a written outcome (`✓`, `✗ exit 2`), with the exact `$ command` on a line under it. A row without a sentence looks as before. Beta: `beta.compactShell` (TUI config) and Settings → Beta → Compact shell rows (iPhone) show the `$ command` line only when the command fails.
