- **Deploying the relay is now a one-page runbook, not a guesswork session.** `apps/relay/deploy/` carries the compile script (`bun apps/relay/deploy/build.ts` → a Linux x64 `dist/tentacle-relay`), a hardened systemd unit (dedicated `relay` user, loopback-only bind, `Restart=always`, no capability) and the Caddy site block with the `stream_close_delay` that stops a config reload from cutting every live phone session; `docs/ops/relay-deploy.md` walks install, TLS, smoke test, upgrade and rollback. Nothing is applied by the repo: running it on the host stays the owner's step. Design: `docs/feat/mobile-relay.md`.
