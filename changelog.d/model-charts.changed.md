- **Charts now draw in the Mac TUI.** A `chart` tool call renders its chart in the conversation's own place — the braille plot, the ⅛-cell bars, the stacked rows, the 100 % pie bar and the sparkline rows (one per series at 40–59 columns; the data table below 40), centred to the transcript width — instead of a generic `● Chart …` tool row and its one-line result: the chart is part of the reply, not a tool block (it keeps no bullet, no connector, and is exempt from the generic body cut). It is drawn from the call's own arguments, re-validated by the client with the same caps as the daemon, so a resumed session shows the same chart and a forged or unreadable spec falls back to the plain tool row rather than crashing. Ctrl+O — or a click on the chart's caption — expands it to 16 plot rows with per-series min/max/last and the data table. A new `tui.chartGlyphs` setting (`braille`, the default, or `blocks`) draws quadrant blocks for a font that has no braille patterns, which a terminal cannot report on its own. Design: `docs/feat/model-charts.md`.
