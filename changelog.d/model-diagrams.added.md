- **The model can draw Mermaid diagrams.** A new `diagram` tool takes a title and a Mermaid source (flowchart, sequence, class, state, ER, gantt, mindmap, timeline, journey, gitGraph; numbers stay with `chart`). The daemon checks it with Mermaid's own parser (loaded on first use; about 3.8 MiB more in the binary), and every mistake comes back as one sentence with the model's own line and the fix — a bracketed label, `->` for `-->`, a message without its colon, a misspelt type — so a small model repairs it in one retry. A Markdown fence, `%%{init}%%` and hard-coded styling are dropped with a note instead of a refusal. The row shows the diagram's title; drawing it inline (an ASCII rendering in the terminal, the phone's renderer) follows. Not offered to sub-agents.
