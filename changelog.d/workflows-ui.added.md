- **Workflows: one step's prompt and report are now readable from any client.** A new `session/workflow_step` read answers the resolved `prompt` and the `report` of a single step execution — the detail a run's live row deliberately does not carry — choosing the newest attempt by default or the `attempt`/`round` asked for, and saying "not available" (an empty answer) for a step that never ran or whose record a compaction has since dropped, rather than showing another step's text. A step still running answers as live, with its prompt and no report. The client reads it — and a run's live list, and the start / stop / resume / re-run-step actions — through one bounded, sanitized seam per session (`@tentacle/client`'s `workflows` module), so a `serve` daemon's runs reach every attached terminal and phone; from a daemon this client does not trust to run workflows (a pod under `run`/`attach`) the list is dropped and every action refuses locally, sending nothing.
