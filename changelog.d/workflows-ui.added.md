- **Workflows: one step's prompt and report are now readable from any client.** A new `session/workflow_step` read answers the resolved `prompt` and the `report` of a single step execution — the detail a run's live row deliberately does not carry — choosing the newest attempt by default or the `attempt`/`round` asked for, and saying "not available" (an empty answer) for a step that never ran or whose record a compaction has since dropped, rather than showing another step's text.
