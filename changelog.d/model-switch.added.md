- **`/model <name>` switches the model of a running session, and `--model` takes a `models` entry.** `/model` lists the main model and every `models.<name>` entry; `/model <name>` moves the session to that entry from the next model request (same history, its endpoint, key and context window), and `/model default` goes back. Works in local sessions and `connect` → `serve`, between turns, for the live session only (not saved). `tentacle --model haiku` starts a local session on that entry; `run`, `attach` and `serve` refuse an entry name. Container sessions cannot switch.
