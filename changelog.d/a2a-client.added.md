- **tentacle can hand a sub-task to a remote A2A agent.** Configure one under `harnesses.<name>` with `"adapter": "a2a"`, its `card` URL and an optional `tokenCommand` (a command printing the token, never the token itself); the agent can then start it as the sub-agent type `a2a:<name>`. Every send (the task, and each reply to the agent's questions) goes through the permission prompt first, with secrets masked; auto mode answers that prompt, and "always" covers that one agent for the session. Only the task text leaves the machine, and the agent's report is marked as remote content. Laptop and `serve` only: a pod never offers it.
