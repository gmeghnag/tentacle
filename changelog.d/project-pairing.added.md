- **Pairing is per project.** `tentacle pair` pairs the phone with the `serve` of the folder it runs in (`--project <dir>` for another), and only that one; with no `serve` running there it refuses. A `serve` with no device paired to it never dials the relay, and its direct address names it (`/s/<id>/e2e`). `tentacle devices` groups by project, and `revoke` acts on one project (`--project`, or `--all-projects`). A phone paired before keeps working, with no re-pairing, on the first project it connects to. Restart every running `serve` after upgrading: an older `serve` refuses the new registry and admits no device. The app needs an update to pair a new project (an older app is told to update).
