- **The model can present artifacts — images, HTML pages, PDFs, Markdown and files — on the Mac and the iPhone.** A new `present` tool snapshots a workspace file (confined to the workspace, secret-looking names refused) or generated text into the session's artifact store, versioned per artifact and content-addressed; the transcript shows a card under the tool row and a gallery lists every version. The bytes travel back over the existing session connection in resumable 256 KiB chunks (`artifact/list`, `artifact/read`, additive — no version bump), verified against the announced sha256 so a pod cannot hand the laptop other bytes, and every viewer treats the content as untrusted: HTML/SVG is CSP-wrapped with no network, and an `other` kind is only ever saved, never opened. On the iPhone, images open in a pinch-to-zoom viewer, Markdown and text render natively, PDFs render in a script-less view of the verified cached file, and HTML/SVG run in an isolated web view (no network until you tap Allow for that one open, no cookies or storage kept, no bridge to the app, and no navigation or link — not even `sms:` or another app's link — leaves the page); any other file can only be shared. A local session's versions are also kept on the laptop beside its log, so `--resume` shows the gallery again — a pod's are never written there. Design: `docs/feat/model-artifacts.md`.
