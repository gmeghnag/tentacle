- **The model can present artifacts — images, HTML pages, PDFs, Markdown and files — on the Mac and the iPhone.** A new `present` tool snapshots a workspace file (confined to the workspace, secret-looking names refused) or generated text into the session's artifact store, versioned per artifact and content-addressed; the transcript shows a card under the tool row and a gallery lists every version. The bytes travel back over the existing session connection in resumable 256 KiB chunks (`artifact/list`, `artifact/read`, additive — no version bump), verified against the announced sha256 so a pod cannot hand the laptop other bytes, and every viewer treats the content as untrusted: HTML/SVG is CSP-wrapped with no network, and an `other` kind is only ever saved, never opened.
