- **Sub-agents on another agent harness: `claude`.** On the laptop and on a `serve` you own (never in a pod), when `claude` is on PATH the agent is offered an `agent_task` type `claude`: Claude Code runs headless in its own git worktree holding a snapshot of your tree (uncommitted changes included), with the model chosen per call (`opus`, `sonnet`, `haiku` or a full id; default `harnesses.claude-code.model`). Every permission Claude Code asks for comes to you through the usual prompt (TUI or phone), attributed to the sub-agent, and follows auto mode: with auto mode on everything in the run passes; with it off, edits inside its worktree pass and commands or anything outside are asked. Your session's grants and `tool_call` hooks apply. Its report ends with the list-price cost, the 5 h / 7 d plan usage and the `claude --resume` session; a worktree it changed is kept on its own branch, never merged. New `harnesses` config section.
