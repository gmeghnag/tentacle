- **`tentacle serve` is an MCP server.** `--mcp-token` / `--mcp-token-command` turn on a Streamable HTTP endpoint (`POST /mcp`, both the legacy `initialize` and the 2026-07-28 `server/discover` forms) on its own bearer token, so Claude Code and other MCP clients can start, steer, watch and cancel tentacle sessions that also show up on your phone. Clients that support MCP tasks get one per turn; the others get non-blocking tools plus a `session_status` wait.
