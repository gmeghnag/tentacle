- **Charts in the conversation — the shared spec and math.** The agent can draw the numbers it talks about instead of only quoting them. A chart is a small, strict spec in the shape of Chart.js (line, bar, area, pie, doughnut, scatter; per-axis unit, `compact`/`full` format and decimals; ISO dates kept honestly apart as calendar, instant and floating) which rides the tool call's own arguments — so it survives a reload and needs no round trip — and styling is never in it: colours, widths and fonts are the client's. A validation error is a plain sentence carrying the fix (`datasets[0].data[0] is the string "12.5" — write the number 12.5 (no quotes)`), every error at once, so a small model repairs it in one retry; the caps are named with their advice (8 series, 1 000 points, 60 bar categories, 64 KiB). Axis ticks, number formatting (our own `k`/`M`/`G` — CLDR's Italian compact form loses the digits), date handling across DST, LTTB downsampling that keeps a single spike among 1 000 points, the summary line the model and VoiceOver read, and a CVD-validated 8-slot palette are one shared, unit-tested module in `@tentacle/core`, so the Mac and the iPhone will draw the same numbers in the same colours. Design: `docs/feat/model-charts.md`.
