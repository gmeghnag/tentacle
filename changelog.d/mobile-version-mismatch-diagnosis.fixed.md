- **The phone names which side to update when it is older (or newer) than its `serve`'s protocol.** A paired computer whose `initialize` is refused with `VersionMismatch` now reads «Update the app» or «Update tentacle» — with the two protocol numbers («app protocol 28, serve 31») — instead of «Stopped · run `tentacle serve`» (a daemon that was running and answering) or «Not reachable», and its section reads «Needs attention» rather than «Offline». The side is derived from the protocol numbers in the daemon's own report, never from its text; a serve too old to send a report counts as the older side, and an unreadable report claims nothing. The session list's failure banner for the same error now names the side and offers no Retry, which no retry could fix.
