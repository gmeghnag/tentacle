- **`sessionHop.tool` turns the agent's `move_session` proposal off.** New setting (default on) and its env form `TENTACLE_SESSION_HOP_TOOL`: with it off the agent is never offered the tool that proposes moving its session to another target, so the only way to move is a `/move` you type. The tool itself never moves anything — it raises one prompt in your terminal at the end of the turn, which auto-accept never answers and nothing remembers. Design: `docs/feat/session-hop.md`.
