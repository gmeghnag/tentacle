# Noise test vectors

`noise-ik-25519-chachapoly-sha256.json` drives `../noise-vectors.test.ts`
(docs/feat/e2e-channel.md, decision 20). It holds published vectors from two
independent Noise implementations, grouped by source.

## Source

Both files are from the snow repository, at a pinned commit:

- `snow`: `tests/vectors/snow.txt`
  (https://raw.githubusercontent.com/mcginty/snow/8ac60f51cfe3e010c84f0a454cc575ad9204fa12/tests/vectors/snow.txt)
- `cacophony`: `tests/vectors/cacophony.txt`
  (https://raw.githubusercontent.com/mcginty/snow/8ac60f51cfe3e010c84f0a454cc575ad9204fa12/tests/vectors/cacophony.txt),
  generated by cacophony (https://github.com/haskell-cryptography/cacophony).

The pinned snow commit is `8ac60f51cfe3e010c84f0a454cc575ad9204fa12`
("deps: upgrade criterion to 0.8", 2026-03-25).

## Filter

Only entries whose `protocol_name` is exactly
`Noise_IK_25519_ChaChaPoly_SHA256` are kept. PSK, fallback, other DH, cipher
and hash variants are dropped. Each entry is copied unchanged, with the field
names of its source file. snow entries have `init_psks` and `resp_psks` (both
empty here) and no `handshake_hash`. cacophony entries have `handshake_hash`.
Neither has `resp_remote_static`, because IK's responder learns it.

The filter kept one entry per source.

## How these bytes were obtained

Direct download (`curl`) was not permitted in the session that vendored them,
so the entries were read through a fetch tool, not saved byte for byte. They
are trustworthy because an independent implementation reproduces them: the
test re-derives every ciphertext and cacophony's handshake hash and compares
byte for byte. A copying error would fail the test. It could not make it pass.
One field, cacophony's message 2 ciphertext, was ambiguous in the fetched text.
The handshake hash covers that ciphertext and it matches, which settles it.

To confirm the file against upstream, run:

```sh
curl -sSfL https://raw.githubusercontent.com/mcginty/snow/8ac60f51cfe3e010c84f0a454cc575ad9204fa12/tests/vectors/snow.txt \
  | jq '[.vectors[] | select(.protocol_name == "Noise_IK_25519_ChaChaPoly_SHA256")]'
```

Then do the same for `cacophony.txt` and diff each result against this file's
`snow` and `cacophony` arrays.
